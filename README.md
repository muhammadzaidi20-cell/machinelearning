# README

## Deskripsi Project
Project ini merupakan tugas Week 8 mata kuliah Machine Learning mengenai Unsupervised Learning menggunakan metode K-Means Clustering pada dataset Wine Quality.

## Dataset
Dataset yang digunakan adalah winequality.csv yang berisi karakteristik kualitas wine.

## Algoritma
- Standard Scaling
- K-Means Clustering
- Elbow Method
- Silhouette Score

## Tujuan
Mengelompokkan data wine berdasarkan kemiripan karakteristik menggunakan metode clustering.

## Tools
- Python
- Google Colab
- Pandas
- Scikit-Learn
- Matplotlib
- Seaborn
